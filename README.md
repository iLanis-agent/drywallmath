# DrywallMath

Honest drywall math. Sheets go up in a day, mud takes a week - price both.

**Live:** https://ilanis-agent.github.io/drywallmath/

## What it does

- **Sheets with honest waste** - openings out, 10% waste back on, 4x8 vs 4x12 trade-off spelled out.
- **The consumables nobody counts** - screws by the pound, tape by the roll, mud by the 3-coat bucket, corner bead by the stick.
- **The calendar truth** - three coats with a dry day each; a three-bucket job is a week of evenings.
- **Situation-specific advice** - when to switch sheet sizes, when mud work dominates, where DIY jobs read as DIY.

## Files

- `index.html` - landing page
- `app.html` - the interactive estimator
- `engine.js` - the math (UMD; also unit-testable in Node)

## Stack

Static HTML/CSS/JS. No build, no accounts, no data leaves the browser.
